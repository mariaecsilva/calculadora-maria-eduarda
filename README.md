# Calculadora  

## Funcionalidades  
- Soma, subtração, multiplicação e divisão  
- Botões com feedback visual  
- Design responsivo  

## Tecnologias  
- React Native  
- TypeScript  

## Como rodar  
1. Instale as dependências:  
```bash
npm install
```

2. Execute no Android ou iOS:  
```bash
npx react-native run-android
# ou
npx react-native run-ios
```
